# Upload recovery release checklist

The fixed [R1–R8 acceptance conditions](upload-recovery-corrective-acceptance.md#required-acceptance),
qualified evidence and remaining limits now share one maintained record.
Use the [local commit/push gate](../AGENTS.md#local-commit-and-push-gate) for
delivery. Earlier detailed attempts remain available through that record's
[historical evidence](upload-recovery-corrective-acceptance.md#historical-evidence).
